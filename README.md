# Рандомайзер на Go

На главном экране запускается розыгрыш и показывается выпавшее число. Чтобы настроить его, нажми на шестерёнку, введи общий список и при желании задай очередь результатов. Нажми «Сохранить и вернуться».

Например, с общим списком `1, 2, 3, 4, 5, 6` и заданной очередью `6, 2, 6` первые три результата будут `6 → 2 → 6`. Затем сервер будет случайно выбирать из общего списка. В настройках можно начать очередь заново.

Списки принимают целые числа, в том числе отрицательные, ноль и повторы. Разделяй их запятыми, точками с запятой, пробелами или новой строкой. При случайном выборе каждое вхождение в список равновероятно. Заданный результат может быть за пределами общего списка.

Настройки, позиция очереди и последний результат сохраняются в браузере для текущего адреса сайта. Go-сервер обрабатывает их при проверке настроек и розыгрыше. Для работы сайта достаточно одного процесса Go, база данных не нужна.

## Запуск на Windows

Установи Go 1.26 или новее, открой PowerShell в папке с `go.mod` и запусти сервер. [Установка Go](https://go.dev/doc/install)

```powershell
go run .
```

Открой [http://localhost:8080](http://localhost:8080). Чтобы остановить сервер, нажми `Ctrl+C` в PowerShell.

## Хостинг на Northflank

Для этого сайта подходит бесплатный план **Sandbox**. По условиям Northflank карта для него не нужна, а сервис остаётся запущенным в пределах бесплатного лимита. [Тарифы Northflank](https://northflank.com/pricing)

1. Распакуй `randomizer-go.zip`. Если Go-сайт уже лежит в GitHub, добавь новый `Dockerfile` рядом с `go.mod` и отправь коммит. Если репозитория ещё нет, создай пустой репозиторий и выполни команды в распакованной папке, подставив свой адрес.

   ```powershell
   git init -b main
   git add .
   git commit -m "Add Go randomizer"
   git remote add origin https://github.com/USERNAME/REPOSITORY.git
   git push -u origin main
   ```

2. В Northflank выбери план **Sandbox**, создай проект на **Northflank Cloud** и подключи GitHub. При подключении предоставь доступ к репозиторию с рандомайзером. [Создание проекта](https://northflank.com/docs/v1/application/getting-started/create-a-project) · [Подключение GitHub](https://northflank.com/docs/v1/application/getting-started/link-your-git-account)
3. В проекте выбери **Create new → Service → Combined**. Выбери репозиторий, ветку `main` и способ сборки **Dockerfile**. Если файлы Go-сайта находятся в корне репозитория, оставь путь и контекст сборки по умолчанию. Для репозитория со всем рабочим каталогом укажи путь `go-web/Dockerfile` и контекст `go-web`. Нажми **Create service**. [Сборка и запуск сервиса](https://northflank.com/docs/v1/application/getting-started/build-and-deploy-your-code)
4. Когда сборка завершится, в **Configure → Networking** проверь, что порт `8080` настроен как **HTTP → Public**. Если его нет, добавь порт с этими значениями. Открой сгенерированный HTTPS-адрес на `code.run` на компьютере или iPhone. [Публичные порты и адрес сайта](https://northflank.com/docs/v1/application/network/configure-ports)
